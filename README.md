# PickaxeEnchantments

A lightweight Minecraft plugin that adds custom enchantments and upgrades for pickaxes.

## Features
- Adds unique pickaxe enchantments (Magnetic, Smelting, Veinminer and Hammer.)
- Simple setup plug and play.
- Works on Spigot/Paper servers
- Designed to be lightweight and easy to use

## Installation
1. Download the plugin jar.
2. Place it in your server's `plugins` folder.
3. Restart your server or reload the plugin.
4. Edit the generated config file to customize settings if needed.

## Configuration
After the first run, a config file will be created in the plugin folder. Adjust the values to match your server preferences.

## Notes
- This plugin is intended for Minecraft servers running Spigot or Paper.
- Make sure you are using a compatible version of the server software.
